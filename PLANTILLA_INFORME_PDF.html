3. Arquitectura y Tecnologías Utilizadas

Backend & Base de Datos

  • Node.js & Express.js: Servidor RESTful asíncrono.
  • SQLite3: Base de datos relacional persistente en disco (database.sqlite).
  • CORS & Dotenv: Habilitación multiplataforma y gestión de entornos.
  • Render Cloud: Despliegue en la nube con certificado HTTPS automático.

Frontend Móvil

  • Flutter & Dart: Interfaz moderna con Material 3.
  • Dio: Cliente HTTP avanzado con interceptores y manejo tipado de errores.
  • go_router: Enrutamiento declarativo y navegación anidada (ShellRoute).
  • Provider: Gestión de estado reactiva (ChangeNotifier).
  • flutter_dotenv: Variables de entorno externas.

4. Esquema de Base de Datos y Endpoints

CREATE TABLE IF NOT EXISTS productos (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  nombre TEXT NOT NULL,
  codigo TEXT UNIQUE NOT NULL,
  descripcion TEXT,
  precio REAL NOT NULL,
  cantidad INTEGER NOT NULL,
  categoria TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
MétodoEndpointFuncionalidadCódigo HTTP
GET/api/productosListar todos los productos200 OK
GET/api/productos/statsMétricas calculadas del Dashboard200 OK
GET/api/productos/:idConsultar detalle por ID200 OK / 404
POST/api/productosRegistrar nuevo producto (validador único)201 Created / 422
PUT/api/productos/:idActualizar producto existente200 OK / 422
DELETE/api/productos/:idEliminar producto con confirmación200 OK / 404
